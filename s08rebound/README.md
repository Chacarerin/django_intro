# Semana 8: Rebound

Práctica avanzada sobre grupos y permisos granulares de usuario.

## Objetivos del Ejercicio
- **Control de Acceso (RBAC):** Asignación de roles a través del sistema de Grupos (Groups) en la base de datos de Django.
- **Permisos Personalizados:** Definición de permisos específicos a nivel de modelo para restringir acciones puntuales (por ejemplo, permitir ver un registro pero no editarlo).
- **Protección de Plantillas:** Uso de etiquetas `{% if perms %}` para ocultar botones e interfaz de usuario según los privilegios del cliente actual.
