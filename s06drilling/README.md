# Semana 6: Drilling

Ejercicio centrado en la captura de datos del usuario y validaciones mediante el sistema de Formularios nativos de Django (`django.forms`).

## Objetivos del Ejercicio
- **Clases de Formulario:** Definición de campos (CharField, EmailField, IntegerField) directamente en Python.
- **Renderizado:** Presentación automática de formularios en las plantillas usando `{{ form.as_p }}`.
- **Manejo de POST:** Procesamiento lógico de la petición (request.POST), validación de datos mediante `form.is_valid()` y extracción segura a través de `form.cleaned_data`.
