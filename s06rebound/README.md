# Semana 6: Rebound

Refuerzo práctico de los conceptos de formularios, esta vez orientados hacia la vinculación directa con la base de datos a través de `ModelForms`.

## Objetivos del Ejercicio
- **ModelForms:** Creación de formularios que heredan automáticamente la estructura, validaciones y reglas de negocio definidas en los Modelos (`models.py`).
- **Operaciones de Escritura:** Guardado eficiente de nuevos registros directamente desde el formulario usando `form.save()`.
- **Mensajes Flash:** Integración del framework de mensajes de Django para notificar al usuario sobre el éxito o fracaso de su envío.
