# Semana 1: Drilling

Ejercicio introductorio que abarca la instalación y configuración inicial de un proyecto Django desde cero.

## Objetivos del Ejercicio
- **Estructura Base:** Inicialización del proyecto mediante `django-admin startproject` y creación de la primera aplicación con `python manage.py startapp`.
- **Rutas y Vistas Básicas:** Configuración del archivo `urls.py` tanto a nivel de proyecto como de aplicación, enlazando peticiones HTTP con vistas funcionales simples.
- **Respuesta HTTP:** Retorno de cadenas de texto básicas a través de `HttpResponse` para confirmar el correcto funcionamiento del servidor local.
