El inicio formativo se centra en el despliegue del esqueleto basal del Framework. El objetivo académico es interiorizar los mecanismos mediante los cuales Django interconecta peticiones de un navegador con lógicas de servidor.

## 📌 Contenidos Principales
- **Inicialización y Modularidad:** Empleo del cliente `django-admin` y `manage.py` para comprender la jerarquía directorios y la estricta separación de responsabilidades entre el 'Proyecto' (entorno global) y la 'App' (componente funcional autónomo).
- **Enrutamiento HTTP (URLs):** Estudio sintáctico del módulo `urls.py`. Cómo se construye el árbol de rutas jerárquicas y su vinculación explícita con métodos receptores (views).
- **Procesamiento de Retorno (HttpResponse):** Verificación de peticiones correctas emitiendo cadenas de texto serializadas directamente, previo a la introducción de motores de plantillas complejos.

## ⚙️ Tecnologías y Frameworks Aplicados
- **Django URL Dispatcher:** Motor que procesa expresiones regulares y cadenas simples, comparando la ruta solicitada por el usuario (URL) y disparando la ejecución del código Python correspondiente en milisegundos.
