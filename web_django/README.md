# Web Django

Un enfoque práctico sobre la renderización de datos y componentes visuales, orientándose a construir un sitio web dinámico y estilizado.

## Características Técnicas
- **Integración de Frameworks CSS:** Preparación de las plantillas base para incluir frameworks de diseño como Bootstrap.
- **Vistas Parametrizadas:** Generación de contenido dinámico dependiendo de los parámetros pasados en la URL o de consultas simples a la base de datos simulada.
- **Modularidad de Plantillas:** Uso de la etiqueta `{% include %}` para fraccionar código HTML repetitivo (como Navbars o Footers) en archivos independientes, manteniendo un código limpio (DRY).
