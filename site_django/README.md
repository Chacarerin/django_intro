# Site Django

Aplicación construida para demostrar la integración de diseños front-end profesionales dentro de la estructura de vistas y plantillas de Django.

## Características Técnicas
- **Archivos Estáticos (Static Files):** Uso estructurado de carpetas estáticas para organizar hojas de estilo CSS y archivos JavaScript personalizados.
- **Etiquetas de Plantilla (Template Tags):** Uso del tag `{% load static %}` en la cabecera para referenciar los recursos desde el servidor.
- **Despliegue de Media:** Configuración básica para manejar la visualización estática de componentes gráficos.
