Proyecto diseñado para afianzar metodologías eficientes en la integración de diseño front-end dentro del ciclo de vida de un proyecto backend.

## 📌 Contenidos Principales
- **Gestión de Recursos Estáticos (Static Files):** Comprensión profunda de la directiva `STATICFILES_DIRS` y la configuración para despachar archivos estáticos durante el ciclo de desarrollo versus producción (con `collectstatic`).
- **Integración de Componentes Media:** Configuraciones requeridas para procesar y servir imágenes o documentos subidos dinámicamente por los usuarios.
- **Rutas Relativas vs Absolutas:** El uso del tag `{% static %}` para asegurar que las referencias a hojas de estilo no se rompan independientemente de la profundidad de la URL actual.

## ⚙️ Tecnologías y Frameworks Aplicados
- **Django Static Storage:** Un mecanismo vital para aislar los recursos de diseño del código fuente de Python, facilitando un despliegue optimizado mediante CDNs (Content Delivery Networks) en arquitecturas productivas.
