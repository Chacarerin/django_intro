# Semana 8: Drilling

Implementación de un sistema robusto de autenticación y autorización de usuarios.

## Objetivos del Ejercicio
- **Sistema de Autenticación:** Incorporación de flujos completos de Login, Logout y Registro utilizando el framework nativo de Django.
- **Gestión de Permisos:** Restricción de acceso a vistas específicas dependiendo del estado de autenticación (usuario anónimo vs. usuario logueado).
- **Decoradores y Mixins:** Uso de `@login_required` para vistas funcionales y `LoginRequiredMixin` para vistas basadas en clases, garantizando la seguridad de la aplicación.
