# Semana 5: Drilling V2

Continuación práctica del ejercicio de la semana 5, enfocado en refinar el código del frontend mediante herencia de plantillas.

## Objetivos del Ejercicio
- **Herencia de Templates:** Creación de un archivo `base.html` que contiene la estructura principal (Header, Navbar, Footer).
- **Bloques Dinámicos:** Uso intensivo de `{% block content %}` para inyectar contenido específico de cada vista secundaria sin duplicar código HTML.
- **Archivos Estáticos:** Configuración e integración inicial de hojas de estilo (CSS) y scripts (JS) desde el directorio estático.
